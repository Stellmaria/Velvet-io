Velvet Anatomy

A private content-management and publishing application used by its owners to organize media and publish selected content to connected platforms.

Pinterest integration Privacy Policy

01

About

An owner-operated archive and publishing workspace.

Velvet Anatomy helps its owners review archived media, prepare selected images for publishing, and send approved content to connected services. The public website does not provide access to the private archive or administrative interface.

02

Pinterest integration

Publishing is initiated by the authenticated account owner.

When Pinterest is connected, Velvet Anatomy uses the Pinterest API to read the authenticated owner account's available boards and to create Pins from media explicitly selected for publication.

✦

Owner controlled

Publication starts only after an owner selects the account, presentation style, board, and confirms the action.

✦

Limited access

The integration requests only the Pinterest permissions required to read boards and manage Pins for connected owner accounts.

✦

No Pinterest passwords

Velvet Anatomy does not ask users to provide Pinterest passwords or Pinterest session cookies.

✦

Privacy

Clear limits on what the integration processes.

Read the policy describing Pinterest API data, authentication credentials, retention, sharing, and user choices.
